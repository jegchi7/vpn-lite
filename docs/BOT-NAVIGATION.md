# Навигация Telegram-бота CHIMERA

Бот работает только в личном чате. После привязки одна учётная запись и один
набор устройств используются в боте и панели. Каждый экран редактирует текущее
сообщение; новый файл или QR отправляются только по явному выбору пользователя.

```mermaid
flowchart TD
  home["Главная"] --> devices["Мои устройства"]
  devices --> card["Карточка устройства"]
  card --> formats["Способ импорта"]
  formats --> delivery["Одноразовая ссылка"]
  delivery --> file["Файл или QR в чате"]
  delivery --> formats
  formats --> card
  card --> devices
  devices --> home
  home --> network["Сеть и маршруты"]
  network --> home
  home --> guide["Инструкция"]
  guide --> home
  home --> account["Учётная запись"]
  account --> home
```

```mermaid
flowchart TD
  devices["Список устройств"] --> name["Ввод названия"]
  name -->|"Валидное название"| card["Созданное устройство"]
  name -->|"Ошибка ввода"| name
  name -->|"Назад, отмена, другая кнопка"| devices
  card --> ask["Подтвердить отзыв"]
  ask -->|"Отмена"| card
  ask -->|"Отозвать"| revoked["Отозванное устройство"]
  devices --> archive["Отозванные"]
  archive --> revoked
  revoked --> erase["Подтвердить удаление"]
  erase -->|"Удалить"| archive
  erase -->|"Отмена"| revoked
  archive --> clear["Подтвердить очистку"]
  clear --> archive
```

```mermaid
flowchart TD
  home["Главная владельца"] --> manage["Управление"]
  manage --> users["Пользователи"]
  users --> user["Карточка пользователя"]
  user --> invite["Приглашение или восстановление"]
  invite --> user
  user --> confirm["Подтвердить блокировку или отзыв"]
  confirm --> user
  user --> users
  users --> manage
  manage --> login["Ввод логина приглашённого"]
  login -->|"Создать"| invite
  login -->|"Отмена"| manage
  manage --> panel["Полная панель управления"]
  manage --> home
```

На экранах первого уровня есть «Главная», глубже — «Назад» и «Главная».
Списки разбиты на страницы
по шесть записей. Отозванные профили отделены от действующих; удаление доступно
только после подтверждённого применения отзыва на сервере. Ошибки возвращают
действующую навигацию, ошибочное название можно исправить следующим сообщением.

Любой переход, `/start`, `/menu` и `/cancel` очищает ожидаемый ввод. Срок ввода —
пять минут. Повторное нажатие старой кнопки заново проверяет владельца устройства,
роль пользователя и текущее состояние в БД. Команды `/invite login` и
`/block login` сохранены; блокировка через команду тоже требует подтверждения.

В 1.2 экран сети показывает страну входа, географию российских и прочих
назначений, выбранный транспорт и свежесть проверки. При зарубежном входе
бот выходит напрямую с зарубежного хоста.
