# CHIMERA 1.1

Переименование относится к продукту, панели, боту и выдаваемым профилям.
Пути `/etc/ruvpn`, `/opt/ruvpn`, unit-имена `ruvpn-*`, существующие cookies
и ключи сохраняют совместимость с установленной версией.

## Интерфейс

Обе панели перенесены с Jinja-страниц на Svelte 5 с серверной авторизацией.
FastAPI передаёт только необходимые поля представления: пароль, чужие
пользовательские ключи и настройки foreign в личный кабинет не попадают.
Владелец получает отдельный API с проверкой роли и секретного URL.
CSRF, проверка Origin, CSP и одноразовые ссылки сохранены.

Русская тёмная тема повторяет референс: зелёные поверхности, лаймовый акцент,
фиксированная навигация, реальные графики и схема RU/foreign. Мобильное меню
раскрывается отдельно. У панели нет управления VPN-приложением на устройстве:
она выдаёт профиль и управляет серверным доступом.

Обычные пользователи устанавливают пароль от 8 символов; владелец — от 12.
Существующие пароли остаются действительными. Приглашение восстановления
действует 24 часа, удаляет сеансы и ключи входа после установки нового пароля,
сохраняет VPN-устройства. Ключи WebAuthn требуют HTTPS и совместимого браузера;
регистрация подтверждается действующим паролем.

## Профили и статистика

- VLESS URI: `fp=hellosafari_16_0`, имя `CHIMERA · устройство`.
- Полный sing-box JSON использует поддерживаемый этим ядром `safari`.
- Нативный Amnezia `vpn://` содержит `description` и AWG 3.1 в `last_config`,
  включая параметры обфускации. `.conf` остаётся отдельным форматом.
- Подтверждённо отозванные устройства удаляются индивидуально и списком;
  удаляются связанные credentials и ссылки скачивания, журнал сохраняется.
- Сбор измерений каждые 10 секунд: общий трафик ядра, число соединений,
  CPU/RAM/uptime RU, AWG transfer/handshake. История хранится 30 дней.
- AWG-счётчики относятся к текущему peer и могут обнулиться при его пересоздании.
  Отдельных счётчиков VLESS по устройствам у текущего API нет.
- Задержка пути — время HTTPS-проверки через транспорт, а не ICMP ping.
  Пропуски и устаревшие измерения не выдаются за нулевую скорость.
- Трафик и пропускная способность не ограничиваются. Сохраняется только
  существующий лимит количества устройств.

## Обновление установленного RU

Релиз содержит собранную панель. На RU не требуется Node.js. Таблицы passkeys,
auth_challenges и metric_samples добавляются через `CREATE TABLE IF NOT EXISTS`;
существующие устройства, ключи, пользователи и таблицы не преобразуются.

Из нового каталога исходников, от root:

```bash
git pull --ff-only
/opt/ruvpn/current/scripts/update.sh "$PWD"
/opt/ruvpn/current/scripts/configure.sh --confirm-network
/opt/ruvpn/current/scripts/status.sh
```

Команды обновления сохраняют текущий setup, bot token и pairing. Установщик
выполняет обычное применение с таймером отката; подтверждение выполняйте только
после проверки сохранённого SSH-доступа в отведённый setup интервал. Межсерверный
SNI, fingerprint и транспорт этим выпуском не меняются. Foreign compat отдельно
обновлять ради интерфейса и профилей не требуется.

Ручной импорт нового Amnezia-формата и WebAuthn на устройствах владельца
выполняются после обновления; ранее подтверждённые AWG `.conf` и VLESS сохранены.
