# Эксплуатация

## Где что находится

| Путь | Назначение |
|---|---|
| /opt/ruvpn/releases | Установленные версии кода и зависимостей |
| /opt/ruvpn/current | Текущий релиз |
| /opt/ruvpn/previous | Предыдущий релиз |
| /etc/ruvpn/setup.json | Применяемые настройки без пользовательских ключей |
| /etc/ruvpn/secrets.json | Root-only секреты узла |
| /etc/ruvpn/paired.json | Root-only параметры межсерверного клиента на RU |
| /etc/ruvpn/vault.key | Ключ шифрования credentials вне БД |
| /etc/ruvpn/public.json | Только RU-параметры для выдачи профилей |
| /etc/ruvpn/control.json | Настройки мониторинга, proxy auth и бот |
| /etc/ruvpn/applied.json | Последняя применённая ревизия helper |
| /etc/ruvpn/lists | Неизменяемые версии базовых списков и указатели |
| /var/lib/ruvpn/control.sqlite3 | Control plane, события и статусы |
| /var/lib/ruvpn-net/cache.db | Кэш ядра, FakeIP и выбранный путь |
| /var/lib/ruvpn-web | Автоматически обновляемые ACME сертификаты панели |

Настройки меняйте через setup.toml + configure.sh. Не редактируйте сгенерированные
sing-box.json и awg.conf: следующее применение их пересоберёт. MTU можно менять
без новых пользователей/ключей; владельцы уже импортированных профилей заново
скачивают тот же профиль с новым MTU.

## Доступ и порты

RU: TCP/443 VLESS; UDP/443 AWG; TCP/8443 панель; TCP/80 HTTP-01; существующий
SSH-порт. Foreign: TCP/443 REALITY и UDP/443 Hysteria2 только с RU; SSH владельца.
UDP и TCP с одинаковым числом порта независимы. DHCP-клиент и ICMP PMTU
сохраняются. Никакие настройки SSH/password login установщик не переписывает.

Служебные 8088, 10081–10083, 19090 слушают loopback. Caddy не включает access
log, uvicorn запущен с --no-access-log. Подробный журнал трафика sing-box выключен,
чтобы не собирать назначения, DNS и URI. Состояния запуска смотрите в systemd,
состояния транспорта — через status.sh и панель.

```bash
/opt/ruvpn/current/scripts/status.sh
systemctl status ruvpn-sing ruvpn-awg ruvpn-helper ruvpn-panel ruvpn-caddy
journalctl -u ruvpn-helper -u ruvpn-panel -n 60 --no-pager
```

На foreign службы AWG/helper/panel/caddy не устанавливаются. Для него достаточно
status.sh и systemctl status ruvpn-sing.

## Типичные действия

**Не применилось устройство/правило:** в панели есть failed revision. Прежнее
состояние не считается успешным отзывом. После устранения ошибки нажмите
«Повторить применение». При недоступности helper статусы транспорта могут быть
устаревшими — панель помечает это.

**Оба транспорта недоступны:** RU_DIRECT не требует foreign. В режиме Auto
selector выбирает closed. Telegram с route=foreign также недоступен; используйте
панель без VPN. Принудительный режим не переключится сам. Изменение режима
видно в следующем цикле контроллера, обычно до 30–40 секунд с сетевым ожиданием.

**Неверная классификация сайта:** добавьте точный домен/suffix в ручные правила
с FOREIGN или RU_DIRECT. Для домена он выше RU-IP и базовых suffix. При меньшем
числе priority правило применяется раньше. Если имя скрыто приложением,
доменное правило может быть недоступно; отключение собственного DoH делает
поведение предсказуемее. CIDR применяется к известному адресу, а не принудительно
разрешает все скрытые имена до выбора транспорта.

**Частный пользовательский сервис:** network.allowed_services допускает
явную пару IP/порт и tcp/udp на другом хосте. Сервис открывается по этому IP.
Служебные адреса самого шлюза, loopback/link-local и клиентские подсети не
разрешаются. Ручное RU_DIRECT для 192.168.0.0/16 не отменяет изоляцию.

**Список источника не обновляется:** останется последняя версия. Ежедневное
задание ruvpn-lists.timer может повторить позже, либо используйте кнопку панели.
Повтор в пределах суток после успешной загрузки отклоняется. Если обновление
не применилось ядром, helper вернёт предыдущий указатель списков.

**Утрачены межсерверные секреты / подошёл срок сертификата:** на foreign:

```bash
/opt/ruvpn/current/scripts/configure.sh --rotate-pair --output /root/ruvpn-pair.ruvpn
```

Это явная ротация: прежние UUID, ключ REALITY, пароли и Hysteria2 сертификат
перестаёт принимать foreign. До импорта нового пакета на RU foreign-трафик
недоступен. Передайте пакет закрытым способом и импортируйте pair.sh на RU.
Пользовательские устройства не меняются. status.sh показывает срок TLS.
Для повторного экспорта без ротации используется --export-pair.

**Изменился RU IPv4:** измените setup на foreign, примените configure.sh и
подтвердите сеть; firewall обновит allowlist. Затем примените новый setup на RU.
Если изменился клиентский endpoint, владельцы устройств скачивают обновлённые
профили с прежними ключами. Если изменился foreign IP, установите его с новым
setup и пакетом; RU импортирует только пакет, совпадающий с configured foreign IP.

## Обновление и откат

update.sh принимает каталог распакованного релиза, проверяет совпадение номера
схемы данных, ставит его отдельно и сохраняет previous. Несовместимая схема
останавливает обновление вместо неявной миграции. Данные и ключи вне каталога
релиза. Требуется обычное подтверждение сетевого изменения.

rollback.sh возвращает previous и заново компилирует текущие credentials из
БД. Он не восстанавливает устаревшую базу поверх текущих отзывов. Автоматический
сетевой откат использует собственный nftables snapshot и только таблицу/правило
этого продукта. Глобальный ruleset не очищается.

Резервная копия использует AES-256-GCM с аутентификацией и Scrypt KDF, отдельный
случайный salt и nonce. SQLite копируется через backup API. Восстановление
принимает копию той же роли и сетевой идентичности, защищено сетевым таймером
и возвращает credentials на дату копии. После него повторите более поздние
отзывы и смены паролей. Файлы восстановления и пароль храните раздельно.
