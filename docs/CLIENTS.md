# Клиенты и формат профилей

Здесь указаны целевые версии и форматы, под которые сформирована поставка.
Реальный импорт на личных устройствах владельца из этой среды не выполнялся.

| Профиль | Целевой клиент | Особенности |
|---|---|---|
| AWG .conf / QR | AmneziaVPN 5.0.3.0, Android/Windows/Linux, поддержка протокола AWG 3.1 | HeaderProtectionKey, S1–S4=24, H1–H4=1/2/3/4, RandomTrailers=on, ContentPaddingAddition; не обычный WireGuard |
| VLESS URI / QR | v2rayN 7.25.6 с ядром, поддерживающим VLESS REALITY + Vision | Включить TUN/VPN, DNS через gateway, захват/блокировку IPv6 и kill switch в самом клиенте |
| sing-box JSON | sing-box 1.14.3 и приложения, принимающие полную конфигурацию этого ядра | TUN с auto_route/strict_route на клиенте, IPv6 reject и управляемый DNS уже в JSON |
| iOS | Требуется доступный в регионе клиент с AWG 3.1 либо REALITY/Vision и полным VPN | Наличие подходящей версии в App Store и импорт конкретного формата не подтверждены; старые AWG 1/2 приложения с 3.1 не совместимы |

AmneziaVPN и отдельный AmneziaWG — разные приложения. Версия приложения
и версия протокола также различаются: слово «3.1» относится к параметрам
протокола, а не означает совместимость любого приложения с номером 3.1.
Формат 3.1 выбран сознательно; установщик не понижает его до AWG 2.0.

Для AWG достаточно полного импорта .conf с AllowedIPs 0.0.0.0/0, ::/0.
Профиль включает IPv6 адрес устройства, хотя интернет-выход IPv6 закрыт.
Если клиент игнорирует IPv6/kill switch, сервер не может остановить трафик,
который устройство отправило мимо VPN. Это настройка самого приложения/ОС.

VLESS URI содержит только RU endpoint и пользовательский UUID/публичные
параметры RU REALITY. URI не стандартизует все параметры DNS и VPN каждого
приложения. Для полного охвата нужен TUN/VPN; server gateway DNS по умолчанию
10.77.0.1. Не выбирайте режим одного браузерного прокси, если нужен весь трафик.

Полный JSON рассчитан на sing-box 1.14.3. Его не нужно вставлять в импорт
WireGuard/Amnezia .conf или в поле VLESS URL. Режим auto_route включён только
на клиенте; на сервере он всегда ограничен отдельной policy table.

В панели у одного устройства есть оба набора credentials. Выбирайте один
протокол для текущего подключения. При сетевой проблеме переключайте профили
вручную; автоматическое переключение AWG ↔ VLESS на устройстве не заявляется.

Из-за закрытого доступа из туннеля к служебным интерфейсам для получения
нового профиля в браузере может потребоваться отключение VPN. Telegram может
оставаться доступен по foreign, но скачивание HTTPS-ссылки идёт через панель.
